# Instrucciones para asistentes de código

Este proyecto usa `GEMINI.md` como archivo de contexto principal (producto, stack, reglas duras y flujo de trabajo).
Léelo antes de cualquier cambio, junto con `docs/TRASPASO.md` y `docs/ANIMACIONES.md`. Para empezar en un chat sin
acceso al repositorio, usa el mensaje inicial de `docs/MIGRACION_GEMINI.md`.
